# Devine Nyaenya

Cybersecurity practitioner in Nairobi focused on application security, authorized security testing and access-control engineering.

I work in systems I own or have explicit permission to assess. My projects combine attack simulation with remediation: map the trust boundary, test the control, preserve the evidence, fix the weakness and rerun the test.

## Selected work

### [Chokepoint](https://github.com/Nyaenya-Devine/chokepoint)
A least-privilege control plane for sensitive human and agent operations. It enforces distinct-requester approval, context-bound mandates and a verifiable audit chain. The test suite covers authorization, cryptography, ledger integrity and anomaly handling.

[Live demonstration](https://chokepoint-demo.vercel.app)

### [Android Reset Lab](https://github.com/Nyaenya-Devine/android-reset-lab)
A simulation for testing abuse paths around irreversible device operations. Seventy-five tests cover authorization, negative paths, detection, workflow safety and sanitization decisions. Attack scenarios include brute force, replay, privilege escalation, unknown devices and unapproved execution.

[Live simulation](https://android-reset-lab.vercel.app)

### [Android Device Management Tool](https://github.com/Nyaenya-Devine/android-device-management-tool)
An experimental Android Enterprise console with explainable fleet posture, policy management and a simulator for high-impact commands. The live Google API path is implemented but remains clearly separated from the public simulation.

[Live demonstration](https://android-device-management-tool.vercel.app)

### [OrbitDesk](https://github.com/Nyaenya-Devine/orbitdesk)
A local-first Modern Workplace operations lab used to practise identity, Conditional Access, endpoint-compliance and audit-driven troubleshooting. It does not connect to a production tenant.

[Open the lab](https://orbitdesk-gamma.vercel.app) · [Product recording](https://orbitdesk-gamma.vercel.app/demo)

### [EndoPima Kenya](https://github.com/Nyaenya-Devine/endopima-kenya)
A bilingual, mobile-first health-awareness and care-navigation prototype. It is not a diagnostic tool and keeps entered information on the device.

[Open the prototype](https://nyaenya-devine.github.io/endopima-kenya/)
