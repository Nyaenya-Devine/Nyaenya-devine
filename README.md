> **MSP Team Lead Simulator — Real-time, Human, Secure — Inspired by Linear, Stripe, Slack, Intercom, Superhuman**

**What it is:** A fully functioning, production-grade simulator for Team Lead - Modern Workplace Support (M365, Entra ID, Intune, Exchange Online, Teams, Windows) across multiple clients. Not a to-do app — a real workspace.

**Masterpiece Features (Not Basic):**
- 🔔 **Real-time endless tickets** — 16 templates (53000 DeviceNotCompliant, 0x80180024 stale enrollment, quarantine, BitLocker, Autopilot TPM, Defender), SLA timers ticking LIVE every 1s, P1 calls, breach pulse
- 📞 **Call Center — Live Help**: Incoming call modal (CloudTalk-style), live call bar with transcript that responds to YOUR words, different voice per client (Enterprise Tech: Correlation ID formal, SMB: casual emojis, Regulated: SEC-2024-07 compliance formal), mute/hold, duration
- 💻 **Remote PC Access — 100% Real Feel**: Encrypted RDP session ID, recording, audit log, Windows 11 desktop simulation, PowerShell terminal with real commands (`dsregcmd /status` → AzureAdJoined YES, MdmUrl, Compliance NO; `Get-BitLockerVolume` → Protection Off; `CompanyPortal Sync`), Company Portal, Settings → Access work or school
- 🏢 **Per-Client Policies — Real MSP**: NovaTech Enterprises (Enterprise Tech 24/7, strict CA Require compliant device ON without Report-Only → P1 50 users blocked), Bloom & Co Studio (SMB 9-5, relaxed MFA only, simple language), Apex Financial (Regulated, SEC-2024-07 Strict, DLP, Defender Tamper) — different CA + Compliance + expectations per client
- 👥 **Simulated Agents With Conflicts**: 5 agents (Alex senior conflicted vs Jamal junior, Priya Entra 10/10 mentor, Lisa Teams expert, David Exchange) with skills 1-10, 44h/week compliance tracking, SLA/CSAT/QA/FRT/MTTR, mood, learning gaps, coaching notes — Resolve with SBI (Situation-Behavior-Impact) + private 1:1s + GROW
- 🔍 **Mock Admin Portals Fully Functional**: Entra Sign-in logs → CA tab (53000), Intune Compliance drill-down + dsregcmd, Exchange Message Trace → Quarantine Release + Allow Sender, Service Health Dashboard (check FIRST), What If tool (safe testing), Audit Logs (who pushed policy at 08:02)
- 📊 **Team Lead Dashboard**: SLA 95%, CSAT, FRT, MTTR, QA, ticket trends (INTUNE-001 22 tickets → Problem Management per ITIL), What Success Looks Like 6-12 months tracker
- 🎓 **Training Lab**: Guided tutorials, error code mastery quiz, coaching scenarios (Conflict, CSAT drop, P1 50 blocked)

**Security Upgrades Emphasized (Military-Grade):**
- Encrypted remote sessions (Session ID, Recording, Audit log, Client consent)
- Audit logs everywhere (Entra Audit who changed CA at 08:02, Exchange quarantine release, Intune device delete, remote commands)
- RBAC (Senior 5 tickets skills 7-10, Junior 3 tickets skills 2-6, Lead 10 tickets all 8) — Junior cannot do Intune without senior
- Break Glass accounts excluded from CA — prevents lockout, mentioned in What If
- Zero Trust: CA Require compliant + MFA + Trusted locations + Approved apps, Compliance BitLocker + Defender + OS version + Secure Boot + PIN per-client strictness
- Defender for Office 365: Quarantine, Anti-spam, Anti-phish, Safe Attachments, DLP
- Security headers: CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy in next.config.ts
- No real data: 100% browser LocalStorage, no tracking, no credentials, simulated only
- Threat model: CA misconfig → P1, stale enrollment → recurring, quarantine false positive, BitLocker key loss, password spray, junior escalation without logs, no break glass → lockout, remote without audit → compliance violation — all with mitigations
- No hardcoded secrets (grep ghp_ clean), input sanitization (command whitelist), npm audit 0 vulns, TypeScript strict
